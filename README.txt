《蒼穹決戰：星界牌陣》v2.0 GitHub Pages 發布版

發布修訂：2.0.2
- 手機首頁標題改用穩定的實心中文字，不再出現描邊錯位。
- 戰鬥介面依瀏覽器實際可視高度縮放，手機與桌機皆固定在單一畫面內，不需上下捲動。
- 手牌改為底部左右滑動；行動力、出牌上限與結束回合按鈕固定顯示。
- 難度標籤與界域名稱整合進戰鬥標題列，不會超出面板。

啟動方式
1. 解壓縮 ZIP。
2. 雙擊 index.html。
3. 使用 Chrome、Edge 或 Firefox 開啟即可遊玩，不需要安裝程式或連接網路。

遊戲玩法
- 完整流程為：選擇角色 → 自行選擇支援牌 → 選擇難度與反派 → 卡牌戰鬥。
- 從 6 名契約者中選擇 1 名，再親自依職業容量選滿 2～3 張支援術式；系統不會預先裝備。
- 每張支援牌會標示最推薦的職業，但所有角色仍可自由選擇。
- 支援牌選完後，會進入獨立頁面選擇 6 名反派之一，以及簡單、普通或困難。
- 每名角色的初始星能、行動點、每回合抽牌數與出牌上限都不同。
- 點擊卡牌即可使用；卡牌右上角數字是所需行動點。
- 觀察畫面中央的「敵方意圖」，決定要防禦、恢復或全力進攻。
- 攻擊與戰術牌會累積星能，終結牌需要足夠星能才能使用。
- 點擊「結束回合」後，敵人才會執行預告的行動。

內容
- 6 名原創角色：玄劍師、破軍劍士、星術法師、守陣坦克、天弓射手、影刃刺客
- 每名角色皆有不同基礎數值、專屬牌組與 2 項會實際影響戰鬥的天賦
- 12 種支援術式卡牌，並標示最適合的推薦職業
- 11 種牌型：攻擊、防禦、術法、持續、反擊、召喚、回復、異常、連擊、戰術、終結
- 6 名反派：獄骸、血月魔尊、九尾妖皇、墮星劍仙、燭龍君、無相天魔
- 每名反派皆有專屬立繪、戰鬥場景、招式循環與特殊能力
- 灼燒、中毒、流血、破綻、弱化、封鎖、再生、召喚、逆命與反擊等系統
- 原創角色立繪、反派立繪與多張修仙／劍與魔法星界戰場背景
- 電腦與手機響應式介面
- 低生命警戒效果：生命低於 50% 時戰場轉紅，低於 25% 時進入脈動警報
- 更清楚的生命、星能、護盾與 Buff／Debuff 狀態面板
- 首頁與玩法視窗提供完整規則，選角頁也會解釋行動力、手牌、出牌上限、初始星能與支援容量
- 戰鬥卡牌會直接顯示傷害、護盾、治療、抽牌、星能與狀態數值，以及目前不能使用的原因

發布到 GitHub Pages
1. 解壓縮 ZIP 後，直接把裡面的所有檔案與 assets 資料夾拖到 GitHub 儲存庫最外層。
2. 確認 index.html 與 assets 資料夾位於同一層，不要再多包一層資料夾。
3. 到儲存庫 Settings → Pages。
4. Source 選擇 Deploy from a branch。
5. Branch 選 main，資料夾選 /(root)，按 Save。
6. 等待 GitHub 完成發布後即可從 Pages 網址遊玩。
7. 更完整說明請查看 DEPLOY_GITHUB.txt。

檔案結構
