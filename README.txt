《蒼穹決戰：星界牌陣》離線版

啟動方式
1. 解壓縮 ZIP。
2. 雙擊 index.html。
3. 使用 Chrome、Edge 或 Firefox 開啟即可遊玩，不需要安裝程式或連接網路。

遊戲玩法
- 選擇 1 名契約者與 1 名星靈支援。
- 可選擇簡單、普通或困難；難度會影響 Boss 生命、傷害、護盾與強化。
- 每回合抽至 5 張手牌，並獲得 3 點行動點。
- 點擊卡牌即可使用；卡牌右上角數字是所需行動點。
- 觀察畫面中央的「敵方意圖」，決定要防禦、恢復或全力進攻。
- 普通攻擊會累積星能，終結牌需要足夠星能才能使用。
- 點擊「結束回合」後，敵人才會執行預告的行動。

內容
- 4 名原創角色與 4 套專屬牌組
- 3 名支援者
- 攻擊、防禦、抽牌、治療、灼燒、破綻、弱化、暈眩、反傷
- 敵方意圖與 Boss 行動循環
- 原創角色立繪、敵人立繪與星界戰場背景
- 電腦與手機響應式介面
- 低生命警戒效果：生命低於 50% 時戰場轉紅，低於 25% 時進入脈動警報
- 更清楚的生命、星能、護盾與 Buff／Debuff 狀態面板

檔案結構
index.html：主畫面
style.css：視覺與動畫
game.js：卡牌戰鬥規則
assets/：遊戲立繪與背景圖
